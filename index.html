규칙 기반 평가 후보 · 근육 참고 · 회차별 기록 도구

1. 회원·세션 기본 정보

2. 안전성 확인·진행 범위

완전한 진단·배제 도구가 아닙니다. 현재 우려되는 변화는 촬영 등급보다 우선합니다. 과거 병력만으로 자동 응급 판정하지 않고, 새 변화와 현재 상태를 구분해 기록하세요.

3. 증상·목표·기준 과제

NRS 0은 실제로 통증이 없음을 확인한 경우에 입력하세요. 미측정은 빈칸으로 둡니다. 통증이 없으면 수행·안정감·범위를 비교하세요.

4. 모티피지오 촬영 소견

심각·경계·유지는 결과지의 분류명입니다. 의료적 위험도, 특정 근육의 상태, 통증 원인, 치료 필요성으로 자동 변환하지 않습니다.
촬영에서 확인한 방향·형태 — 선택 사항

5. 추가 평가로 확인한 사실

아래 값은 촬영 결과에서 추정하지 말고, 직접 평가했을 때만 입력하세요. 범위 제한은 평가 방법·조건·증상과 함께 해석합니다.

6. 평가 후보·연관 근육 참고

후보는 입력된 사실을 정리하는 규칙 기반 문장입니다. 임상적으로 검증된 원인 예측이나 자동 처방이 아닙니다. 내용이 맞지 않으면 수정·제외하고, 오늘 확인할 후보를 직접 선택하세요.
다른 촬영 소견의 근육·영역 참고 목록

7. 실제 진행·홈계획·다음 결정

8. 이전 형식 기록·이전 가설 보관

후보를 재생성할 때 기존 가설·평가 기록은 이 영역에 보관합니다. 이전 형식으로 가져온 세션도 원문 데이터로 보존합니다.

회원·회차 기록

이 브라우저의 같은 사이트 저장 공간에 보관됩니다. 다른 기기에 같은 주소로 접속해도 자동 공유되지 않습니다. 이름만으로 회원을 자동 합치지 않습니다.

백업·복원

앱 데이터와 JSON 백업은 이 버전에서 암호화되지 않습니다. 백업 파일을 외부에 공유하지 마세요. Safari 사이트 데이터 삭제, 사생활 보호 모드 종료, 사이트 주소·브라우저 환경 변경 등으로 접근이 달라지거나 데이터가 유실될 수 있습니다.

복원은 현재 새 형식 기록을 교체합니다. 교체 전 현재 데이터 백업을 다운로드한 뒤 확인합니다. 다운로드 파일이 실제 저장됐는지도 확인하세요. 이전 motiRecords 저장 키는 삭제하지 않습니다.

사용 원칙

  • 안전성 확인 → 목표·과제 → 후보 → 평가 → 재평가 → 다음 결정 순서입니다.
  • 촬영 미입력은 유지·정상으로 간주하지 않습니다.
  • 유지 소견도 증상이나 기능 문제를 배제하지 않습니다.
  • 정적 촬영만으로 근육 긴장·약화·고정 변형을 판단하지 않습니다.
  • 근육 참고 목록은 관련 움직임을 떠올리는 목록이지 이상 판정이 아닙니다.
  • 단기 개선은 원인 확정이 아닙니다. 반복·다음 날 반응도 확인합니다.
  • 난이도·부하는 증상, 수행, 회복 반응과 개인 목표를 보고 직접 결정합니다.
  • 수기·운동·기기 사용은 자격·업무 범위·제품 지침·센터 절차를 따릅니다.
  • 목 앞쪽·사각근·늑골 등에 대한 수기 방법이나 강도를 자동 처방하지 않습니다.
  • 본 도구는 의료 평가나 기존 상담·진료 기록을 대체하지 않습니다.

후보 선정 규칙

촬영 참고 목록의 정렬에만 심각 2, 경계 1을 사용합니다. 같은 부위라는 이유로 동점일 때 먼저 표시할 수 있지만, 이것은 화면 정리 규칙이지 임상적 중증도나 확률이 아닙니다. 통증 강도와 방향 미확인은 점수에 더하지 않습니다.

저장·잠금

외부 서버 전송 코드와 외부 스크립트는 포함하지 않았습니다. 다만 배포 사이트에서 별도로 삽입하는 코드까지 보장하지는 않습니다. 화면 잠금은 인증·암호화가 아닙니다. 아이패드 기기 잠금과 백업 접근 관리를 함께 사용하세요.
